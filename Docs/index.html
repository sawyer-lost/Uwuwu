CORE FEATURES

What the simulator provides

CPU Simulation

Basic CPU and instruction simulation for the STC89C52 based project.

Memory

Memory read and write operations can be demonstrated inside the simulator.

Registers

View important processor register values while running a program.

Stack

Study LIFO behaviour using push and pop operations.

Queue

Study FIFO behaviour using enqueue and dequeue operations.

Timers & Interrupts

Project functionality can be documented and demonstrated through the simulator UI.
